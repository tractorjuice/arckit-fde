# ArcKit FDE

ArcKit FDE has moved to **<https://arckit.org/fde/>**.

The pages now live in the ArcKit repository, in [`docs/fde/`](https://github.com/tractorjuice/arc-kit/tree/main/docs/fde), and are published with the rest of arckit.org. Change them there.

This repository only keeps the old addresses working. Each page forwards to its new address, keeping any query string and anchor:

| Old address | New address |
|---|---|
| <https://tractorjuice.github.io/arckit-fde/> | <https://arckit.org/fde/> |
| <https://tractorjuice.github.io/arckit-fde/architects.html> | <https://arckit.org/fde/architects.html> |
| <https://tractorjuice.github.io/arckit-fde/samples/governance-pack.html> | <https://arckit.org/fde/samples/governance-pack.html> |

`assets/` stays so that link previews already shared from the old addresses still show their image.
